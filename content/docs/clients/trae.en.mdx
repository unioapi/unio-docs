## Setup steps

1. Open TRAE Settings → Models → Add custom model.
2. Choose **OpenAI Chat Completion** as the API format.
3. Keep the **Full URL** switch **off** and enter the base address:

   ```text
   https://api.unioapi.com
   ```

4. Fill in a model ID (e.g. `gpt-5.6-sol`; full list: [GET /v1/models](/en/docs/api/models))
   and your API key.
5. TRAE validates the key on save; then pick the model and send a message to verify.

## Key detail: path concatenation

With the Full URL switch off, TRAE **appends the path automatically** based on the API format:

- OpenAI format appends `/v1/chat/completions`;
- Anthropic format appends `/v1/messages`.

So the base address must **not** contain `/v1` or a trailing slash, otherwise the duplicated
path returns 404. If you prefer to control the full path yourself, turn the Full URL switch on
and enter `https://api.unioapi.com/v1/chat/completions`.

## Troubleshooting

| Symptom | Check |
| --- | --- |
| 404 / Invalid URL | The base address contains `/v1` or ends with a slash; fix as above. |
| Validation failed | Confirm the API format matches the model's protocol and the model ID matches [GET /v1/models](/en/docs/api/models). |
| 500 internal error | Try switching the API format (do not pick Anthropic format for OpenAI-protocol models). |
